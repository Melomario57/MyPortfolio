## 📌 Secciones del Portafolio

- 🏠 **Home:** Presentación principal con diseño interactivo y llamada a la acción.
- 👨‍💻 **About Me:** Resumen de mi perfil profesional, enfoque en desarrollo web full-stack, tecnologías clave y uso de herramientas modernas.
- 💻 **Portfolio Projects:** Galería interactiva con modales emergentes que detallan especificaciones, arquitectura y enlaces a proyectos en producción y repositorios:
  - 💎 **KRONO:** E-commerce en producción (React, TypeScript, Next.js, Node.js, MongoDB).
  - 📸 **PicGallery:** Aplicación MERN full-stack con autenticación JWT, logging y despliegue en Oracle Cloud VPS con Nginx y SSL.
  - 🎟️ **DevWebCamp:** Plataforma de conferencias MVC (PHP 8, MySQL, Docker, PayPal Sandbox).
- 📬 **Contact & Resume:** Canales de comunicación directa (correo, teléfono), visor de CV incrustado en tiempo real y opción de descarga directa en PDF.
